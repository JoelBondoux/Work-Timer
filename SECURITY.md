# Security Policy

## Reporting Security Vulnerabilities

If you discover a security vulnerability in Work-Timer, please report it responsibly using GitHub's private vulnerability reporting feature.

### How to Report

1. Go to the [Work-Timer repository](https://github.com/JoelBondoux/Work-Timer)
2. Click the **Security** tab
3. Select **Report a vulnerability**
4. Fill out the vulnerability report form with:
   - A clear description of the vulnerability
   - Steps to reproduce (if applicable)
   - Potential impact
   - Any suggested fixes (optional)

### What to Expect

- Your report will be reviewed privately
- We will acknowledge receipt within 48 hours
- We will work on a fix and coordinate a disclosure timeline with you
- You will be credited in the security advisory (unless you prefer anonymity)

### Security Best Practices for Users

- Keep your Work-Timer installation up to date by running `work-timer update`
- Run the tool with minimal necessary privileges
- Review the source code and MCP tool definitions before using in production
- Do not expose the MCP server to untrusted networks without proper authentication

## Public Discussions

For non-security questions, feature requests, or general discussions, please use [GitHub Discussions](https://github.com/JoelBondoux/Work-Timer/discussions) or open an [Issue](https://github.com/JoelBondoux/Work-Timer/issues).

Thank you for helping keep Work-Timer secure! 🔒
